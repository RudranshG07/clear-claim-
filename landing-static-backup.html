Ledger Agent Stack · DePIN · Hardware-gated

Autonomous claims.
Readable approvals.

Clear-Claim is a keyless agent that manages a DePIN operator's reward claims. It watches your rewards, decides when to claim, and assembles the transaction — then you approve a human-readable claim on your Ledger. The key never leaves the device.

Run the demo See how it works

“The missing layer in agentic crypto isn't an agent that can sign — it's an agent whose signing the human can actually verify.”

01

Two bad options.

DePIN operators run always-on nodes that earn continuously. To claim, today they choose between two ways to lose their funds — the gap behind a large share of the $3B drained in 2025.

Option A · Hot key

Auto-claim with a key in a config file

Copyable by malware, exposed to phishing, a standing target. The pattern behind multiple real 2025–2026 drains of agent and operator wallets.

PRIVATE_KEY=0x8f3a9c… # sitting in .env, forever
Option B · Blind sign

Tap “approve” on an unreadable hash

The operator authorizes a string with no way to verify the amount or destination. A gate behind hardware is meaningless if the screen shows a blank check.

Sign hash 0x23b872dd0000a41f… ? ✋ no idea what this does

03

How it works.

The agent does the work and holds no private key. Signing happens in-process through Ledger's Device Management Kit — demoable on Speculos, no hardware required.

01

Watch

The agent reads your claimable balance and the current gas price — modeled on live WeatherXM reward data.

keyless · viem
02

Decide

It proposes a claim only when the reward clears your floor and gas is below your ceiling. The intelligence layer.

policy
03

Clear-sign

It assembles the tx and hands it to your Ledger via the DMK. You approve a readable “Claim 36.75 RWRD to 0x…”.

erc-7730 · dmk
04

Broadcast

The signed transaction is broadcast. The key never left the device; the agent never saw it.

on-chain

06

Run it yourself.

No key, no faucet, no deploy. The contract self-credits a reward to any operator, so the Speculos default seed just works. Point the agent at the live Amoy contract and approve on your own emulated Ledger.

clear-claim — zsh
# 1 · your own Ledger emulator (Ethereum app)
$ API_PORT=5005 DEVICE_MODEL=flex scripts/run-speculos.sh

# 2 · the keyless agent, pointed at the live contract
$ cd agent && npm install
$ cp .env.amoy-demo.example .env && npm start

live DePIN data (api.weatherxm.com): 6162 stations → ~36.75 WXM/station
